# weekend-planner

[![HAI Scale: A1 — Mostly automated](https://haiscale.amolven.com/badge/A1.svg)](https://haiscale.amolven.com/A1/)

A tiny CLI that turns a weather forecast into a packing list.

## How this was made

Most of the code was written by a coding agent. I wrote the prompts, reviewed every
change, and tested each release by hand, which is tier **A1** on the
[HAI Scale](https://haiscale.amolven.com/).
